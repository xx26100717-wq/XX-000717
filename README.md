# LiveBetter · 人生指南前置工具

这是可直接部署的静态网站。根目录就是 `index.html`，无需 npm、数据库、API Key 或编译。

## GitHub Pages 部署

1. 解压 ZIP，将里面的文件和目录一起上传到你的网站仓库根目录。不要只上传 ZIP，也不要把整站再套进一层文件夹。根目录应能看到 `index.html`、`css/`、`js/`、`data/`、`assets/`、`source/`。
2. 网站入口为本包 `index.html`。更新已有网站时，让本包同名文件替换旧版文件，保留所有目录层级；旧版根目录 `app.js`、`style.css` 不再被这个入口引用。
3. GitHub 仓库 Settings → Pages → Build and deployment，Source 选 Deploy from a branch，选择实际上传的分支（通常 main）及 `/ (root)`，保存。
4. 等待 GitHub Pages 部署成功，打开 GitHub 提供的网址。个人站点和项目子目录站点都可使用，不需要修改文件路径。
5. 本包的 `.nojekyll` 为空文件，建议一并提交；它让 Pages 按静态文件发布。即使上传界面隐藏此文件，本站其余路径也不依赖下划线目录。

## 本地查看

在解压目录打开终端，执行：

```sh
python3 -m http.server 8000
```

再在本机浏览器访问 `http://localhost:8000/`。资源全部随包提供，加载后生成报告、搜索、阅读均不需要联网；只有打开参考文献等外部链接才需联网。

本页没有使用 fetch 加载数据，普通浏览器可以尝试直接双击 `index.html`。本次验证环境的管理策略禁止 `file://`，因此未将直接双击打开列为已验证功能；以上 HTTP 方式和项目子目录访问均已验证。

## 已实现功能

- 年龄、收入、家庭、职业、最大担忧、健康、财富、每周时间共 8 个画像维度，家庭多选、担忧最多 3 项。
- 第一层：优先 5 章、后备 5 章，分别展示推荐原因。
- 第二层：优先 10 条 + 后备 10 条，互不重复，提供章节/条目定位、推荐原因、原文成本、收益、完整证据标注及来源。
- 第三层：个人画像卡、先读 3 章、第一批 6 条建议、30 天行动安排，可勾选并清除本机进度。
- 全部 34 章、665 条建议全文搜索，支持章节和证据筛选、分页、原文弹窗及整章 Markdown。
- Markdown 报告下载、打印 / 浏览器保存 PDF；响应式暖色界面。
- 不依赖外部字体、CDN、后端服务或账号；不上传画像。画像在页面刷新后清空，只有行动进度保存在当前浏览器 localStorage。下载的报告含有画像，请自行保管。

## 推荐规则

标签按章节主题与标题关键词生成，未限制的画像维度用空数组表示；它们是工具新增的匹配规则，不是原作者手工标签。算法位于 `js/engine.js`，可读可修改。

每个维度的匹配权重为：年龄 4、收入 5、家庭 12、职业 10、担忧 16、健康 12、财富 7、时间 2。同一维度最多计入两个匹配值。证据等级和低成本用于小幅排序调整，不能替代适用条件。特殊场景（例如孕产、婴幼儿、残疾）未被画像指明时降低排序；书库始终保留全部条目。每章按得分最高的 3 条的平均值排序，避免长章节仅凭条目多取得优势。前 5 章为优先、接着 5 章为后备，每章取 2 条组成 TOP20，前 3 章各取 2 条组成第一批建议。

行动卡是阅读、核对条件、选择和复盘的安排，不把原文医疗或法律措施自动当作个人可直接执行的处方。请在原文中查看备注，结合现实情况咨询相应专业人士。
